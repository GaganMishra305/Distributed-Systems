# Distributed Systems Core Glossary
- **Split-Brain**: Condition where network failure partitions cluster into independent components, each believing it is the sole active cluster.
- **Quorum**: Minimum number of member votes that a distributed transaction or election must obtain to be valid: $Q > N/2$.
- **Linearizability**: Strongest consistency model; operations appear to execute atomically at a specific point in time between invocation and response.
